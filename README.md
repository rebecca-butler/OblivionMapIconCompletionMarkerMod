# MapIconCompletionMarkerMod
This is a mod for Oblivion Remastered.
Map icons can now be marked as "completed" by clicking on them.
This is particularly useful for Oblivion Gates, as there is no completion marker for them in the base game.

## Requirements
Only the Steam version of the game is currently supported.

## Installation
1. Download and install UE4SS.
2. Donwload the `MapIconCompletionMarkerMod` folder.
3. Move the `MapIconCompletionMarkerMod` folder into `Steam\steamapps\common\Oblivion Remastered\OblivionRemastered\Binaries\Win64\Mods`.
